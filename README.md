# ·

鬼才の芸術家の、プロフィールページ。

`index.html` を開く。それだけで動く。依存はない。

## これは何か

経歴も、肩書も、作品リストも、自己紹介文もない。
ここにある言葉は、画面の読めない人のために置いた一文と、あなたが訪れた日時だけである。

言葉は便利すぎる。「孤独」と書けば孤独が伝わった気になる。
だがそれは伝達であって、表現ではない。
生きてきた過程や衝動が、文の形に収まるなら、そもそも絵を描く必要はなかった。

だからこのページは、言葉の代わりに次のものでできている。

| 章 | 画面に起きること | 意味は書かない |
| --- | --- | --- |
| 点 | 暗闇に一つの点が息をしている。スクロールが始まると震え出す | |
| 線 | 点から一本の線が引かれていく。固定された乱数の種から生まれるので、何度訪れても同じ線になる。鋭く折れる箇所は赤く、途切れる箇所は何も描かれない | |
| 嵐 | 線が砕け、粒になって流れ場の中を漂う。カーソルがゆっくり近づくと粒は寄ってきて、速く動かすと弾け飛び、色が青から熾火へと変わる | |
| 傷 | 押しながらなぞると、画面に跡が残る。跡は数分かけて薄れるが、完全には消えない | |
| 円 | すべてが退き、閉じない円が一筆で描かれる。小さな点が戻り、あなたが来た日時が刻まれる | |

スクロールが時間、カーソルの速さが熱、押す力が傷。
右上の小さな丸を押すと、低い持続音が鳴る。音程はページの位置に、息づかいは手の速さに従う。

深夜に訪れると、全体の色温度がわずかに青へ寄る。
昼には骨の色へ寄る。内面は一枚の静止画ではない。

## 作りながら考えたこと

- プロフィールページの定型（名前・写真・経歴・連絡先）を、一つずつ捨てた。残ったのは「ここに誰かがいた」という事実だけ。
- 過去は変えられない。だから線だけは乱数の種を固定した。嵐と傷は現在であり、訪れるたび、触れるたびに違う。
- 表現を観客に明け渡す箇所を一つ作った。衝動は説明するものではなく、持たせるものだと思った。
- 最後に閉じない円を置いた。閉じれば完成であり、完成は死だから。
- 唯一の文字は日時にした。それは作者の言葉ではなく、あなたがここにいたという記録である。

## 技術

- 単一の HTML。Canvas 2D を三層（線と円、嵐、傷）に分けて重ねている。
- 乱数は `mulberry32`。流れ場は正弦波の重ね合わせ。
- 音は Web Audio の鋸波二本と正弦波一本、ローパスフィルタ、呼吸する LFO。
- `prefers-reduced-motion` に従い、動きを抑える。
- スマートフォンでは縦スクロールが時間、横になぞる動きが傷になる。
